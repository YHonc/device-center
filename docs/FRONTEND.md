# 前端开发

Svelte 5 + TypeScript + Vite。`npm run dev`启动浏览器预览，`npm run build`完成Svelte检查与构建，`npm test`运行行为回归。

## 页面结构

- App主窗：设备概览、常用灯光控制、设置抽屉和连接弹窗。
- Compact：320×320快捷窗口，展示电量、灯光与更多设置入口。
- 设备诊断唯一入口：应用偏好 → 设备诊断。
- MappingPreview：明确使用样本的开发预览，不作为设备结果。

## 状态和交互

浏览器预览拒绝原生命令，展示未知电量与禁用操作。桌面窗口先注册监听，再恢复快照，通过时间顺序避免迟到缓存覆盖事件；卸载释放监听。

设置按后端能力启用：现值、修改预览、应用中、读回结果分别展示。关闭前处理未应用修改和挂灯待发队列。挂灯滑条100ms防抖并补发最终值，读回后更新确认状态。

挂灯内置预设单击应用。自定义预设名称旁的编辑按钮展开原位名称编辑，Enter保存、Escape取消；删除放在编辑区。保存当前灯光后先以默认名称落盘，再进入名称编辑。名称编辑与删除不依赖挂灯在线，跨窗更新或删除会结束旧编辑并提示重新编辑。

米家扫码后优先匹配保存/输入目标，无目标时自动选唯一兼容挂灯；多候选保留手选。导入后自动读取灯状态。Token不存入localStorage，扫码取消停止轮询并取消会话。

主题和减少透明度保存在localStorage；动效尊重系统偏好。样式顺序、组件地图见 ARCHITECTURE.md，视觉目标见 UI_SPEC.md，实际验收见 ACCEPTANCE.md。
