# 新版视觉与交互规范

更新：2026-10-23。用户否定初版截图后启动全面UI重构。本文件定义新版目标与验收条件，不宣称已经实现；旧截图和旧构建不能作为新版验收。产品仍是Windows本地设备中心，Apple材质仅作为浮层和控件的设计参考，不宣称调用Apple原生材质。

## 窗口与信息结构

- 默认窗口目标1040×720逻辑像素，采用自绘顶栏、无系统标题栏。当前配置尺寸如有差异，由实现调整后复核。
- 布局起点：自绘顶栏约52px、主体边距24px、卡间距12–16px；右抽屉宽360–400px，米家模态约480px。长内容在抽屉/模态内部滚动，不拉长首页。这些是本项目设计值，不是官方平台参数。
- 顶栏提供明确的拖动区域、应用名称、当前状态和最小化/最大化或还原/关闭控制；交互控件不划入拖动区。窗口拖动、双击标题区域、贴靠、缩放和系统快捷键必须在真实Windows桌面验证。
- 紧凑dashboard优先在默认尺寸完整呈现三台设备的关键状态与常用动作。顶栏后是简洁设备概览，鼠标、键盘、挂灯保持稳定视觉层级；不以大标题、大空白或装饰图挤出主要控制。
- 设备卡首先回答连接状态、当前读数、确认时间和可执行动作。设备图片/轮廓作辅助，不压过电量和参数，不生成虚构实时数据。
- 高级设置用侧边抽屉承载，保留dashboard上下文；一次只操作一个设备，标明设备身份和当前连接。全局偏好与设备配置分开。关闭抽屉前有待应用改动时明确提示，不悄悄写入。
- 米家配对用分步骤弹窗：用户发起→二维码/登录入口→等待扫码和云端验证→设备选择→本机保存→读取挂灯确认。只有真实后端状态才能推进；设备选择不回显token。

## 视觉基线

采用干净稳定的浅色/深色底、清晰的设备图形和紧凑的参数排版。玻璃只用于有层级意义的浮层、抽屉、弹窗与部分控制，主内容阅读面保持稳定对比度。避免整屏半透明、每个面板同样强模糊和多重发光。

- 使用系统字体，正文和操作标签保持可读；电量、亮度等主读数突出，单位和时间次级显示。
- 同一层级使用一致圆角、边框、阴影和间距。卡片圆角目标约20–24px，控件约10–12px；具体值服从紧凑布局和可读性。
- 材质用静态渐变、有限透明度、细高光边与局部backdrop-filter表达；不引入常驻shader、持续折射或后台循环绘制。
- 不把CSS backdrop-filter当成桌面透底；当前Windows方案可采用窗口内部材质。减少透明度/纯色模式必须保持层级和文字对比，不依赖模糊才能理解内容。
- 状态文字与图标同时表达未知、离线、过期、读取中、待应用、验证中、成功和失败，不只依赖颜色。未知电量不显示0%。

## 交互与真实状态

设备配置遵循读取现值→用户编辑→预览差异→点击应用→读回核对。ATK只开放已证实的回报率和已有DPI档位；KX75只开放已证实的休眠字段，其他能力按后端声明显示原因。完整块CAS失败时要求重新读取和预览，不自动覆盖设备变化。

应用期间提供明确进度，禁止重复冲突提交；保持最后确认值与拟变更值的区别。写入后失败可能意味着设备部分生效，应提示刷新核对，不把预览值当作确认值。挂灯滑条保持合并提交与最终值补发，设备读回前不显示最终成功。

扫码弹窗需要明确区分：二维码加载、可扫码、等待手机确认、需额外验证、二维码过期、网络失败、设备加载、无设备、保存失败和完成。显示实际失效时间或后端状态；没有证据时不伪造倒计时或自动成功。关闭/取消停止前端轮询并妥善结束会话，不保留可再次使用的敏感内容。

## 动画规范

- 动效服务于层级变化和操作反馈：抽屉滑入/退出、弹窗出现/关闭、标签切换、数值确认和状态图标变化。小交互以140–220ms为起点，复杂面板可适度调整，最终以真实桌面观感验收。
- 进入与退出可以采用不同的时长/曲线；不通过大幅缩放、弹跳或长距离运动掩饰等待。处理中可以保留低成本状态指示，不让所有设备卡持续动画。
- 更具体的调试起点为hover140ms、按压90ms、抽屉进入220ms/退出160ms；真实体验不佳时调整并复核，减少动态效果时取消位移与缩放。
- 动画结束不触发协议写入或表示成功。网络等待时展示真实状态；成功反馈只能由读回确认驱动。
- 尊重系统减少动态效果；在减少动态效果模式中使用即时状态切换或短淡入，移除大距离位移、弹跳和循环运动，保留等效文字与焦点反馈。窗口隐藏后停止无意义动画。

## 新版验收

| 类别 | 条件与证据 |
|---|---|
| 布局 | 默认1040×720完整呈现关键状态与操作；窗口缩放、100%/150%/200%系统缩放截图；无内容重叠、裁切或横向溢出 |
| 自绘窗口 | 无重复系统栏；拖动区不吞控件点击；最小化/还原/关闭、贴靠及快捷键真实桌面验证 |
| 抽屉/弹窗 | 键盘可打开关闭、Escape按预期处理、焦点进入并在关闭后返回触发控件；遮罩不允许误操作底层 |
| 扫码流程 | 正常链路及过期、额外验证、取消、无设备、保存失败逐项验证；静态页面和二维码图片不算登录成功 |
| 配置真实性 | 当前值、预览、应用中、读回确认与失败可区分；未支持能力禁用；不发送未知协议 |
| 材质/可访问性 | 明暗、减少透明度、纯色、减少动态效果均可读；键盘焦点与读屏标签正确，状态不只靠颜色 |
| 动效 | 可见状态与真实请求同步；快速打开关闭、重复操作、慢响应和错误下无卡死或错误成功反馈 |
| 资源 | 新版release全进程树独立测量；主窗静止、托盘常驻和扫码操作分场景记录，不用混合样本推导idle达标 |

旧性能记录 `artifacts/performance/20261023T035920305Z-summary.json` 实际观察363.6737931秒，`stopReason=process_tree_exited`、`tenMinuteObservation=false`。采样期间包含扫码操作，不能当作纯idle，也不能得出10分钟预算达标结论。新版至少10分钟稳定态测试仍待执行，需记录硬件、构建、WebView2及完整进程树。
