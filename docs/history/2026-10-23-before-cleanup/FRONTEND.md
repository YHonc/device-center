# 前端实现与验收

日期：2026-10-23。实现使用 Svelte 5、TypeScript、Vite、Tauri 2 API；依赖精确版本由 package-lock.json 锁定。

## 运行

项目根目录执行 `npm ci` 安装依赖，`npm run dev` 启动 http://127.0.0.1:1420，`npm run check` 检查类型与 Svelte，`npm run build` 检查并生成 dist。桌面端执行 `npm run tauri dev`，需要 Rust、Windows 构建工具及 WebView2。

## 已实现

- 三设备主窗：ATK F1、迈从 KX75、小米挂灯 1S；内部 CSS 玻璃材质、响应式布局。
- 明暗主题与减少透明度保存至 localStorage；尊重系统减少动态效果偏好；焦点轮廓、标签与状态文字。
- 浏览器预览明确标注未连接桌面后端，不生成虚构电量或在线状态。
- HID 只读枚举列表展示 VID/PID、接口和 usage；不从枚举名称推断已适配。未匹配鼠标、键盘显示待适配、电量与充电未知；后端明确支持的 ATK 373B:101A 或 KX75 3554:FA09 接口提供手动查询，仍须实机确认。
- 灯 IP/token 配置通过桌面命令提交；token 为密码框，保存后清空且不写 localStorage。前端不知道已保存 token。
- 灯状态读取、开关、亮度与色温；滑条合并待发值，100ms 防抖，释放/键盘 change 补发最终值；单队列串行处理，只有设备读回后更新确认状态。失败保留最后读数并显示过期，禁用控制直到重新读取成功。
- 官方驱动按钮由后端固定品牌命令打开默认浏览器。

## 手工验收清单与边界

1. 浏览器打开，确认预览提示、两项未知电量和未配置挂灯；点击刷新不得出现模拟设备。
2. 切换深色/浅色与减少透明度，重新加载检查偏好；使用 Tab 检查焦点，调整窗口至窄屏与 150%/200% 缩放检查布局。
3. 在桌面端刷新，核对枚举接口与系统设备信息；此结果不代表 F1/KX75 电量适配成功。
4. 输入真实挂灯 IP/token，确认配置保存并读回；拖动滑条后对照实机亮度与色温，快速往返拖动核对最终值；断网验证错误与过期状态，恢复后重新读取。
5. 核对官方驱动按钮从默认浏览器打开；确认浏览器预览中控制禁用。

## 本地设置增量验收

设备设置由独立组件承载，按后端字段能力启用控件；不支持项展示原因。编辑先形成变更预览，用户点击应用后携带完整配置快照进行并发校验，读回确认后才显示成功。失败撤回预览并要求重新读取。KX75 休眠显示秒，0 为永不，范围 0–1200、步长 30；不向用户展示协议 ticks 或配置快照 token。

2026-10-23，主代理使用 CUA in-app browser 在 1265×712 视口、深色与减少透明度状态打开 ATK 设置：未知设备提示正确，所有写控件禁用，滚动后无重叠。这仅验证未连接状态布局，不代表真实字段编辑或设备设置写入验收。此次未重复浏览器调用。

## 米家扫码导入

挂灯连接设置保留手动 IP / Token，新增米家扫码入口。默认中国大陆，可选择支持地区；只有用户点击获取登录二维码才发起登录。不提供没有后端流程支持的密码或验证码输入。二维码仅接受后端返回的 PNG data URL。组件串行查询扫码状态，每次 pending 返回后等待 1.5 秒；过期、错误或取消后停止，卸载时释放后台会话。

登录确认后显示设备名称、型号和 IP，后端判定不支持的设备禁选。只有点击连接所选挂灯才请求后台导入并使用 DPAPI 保存，前端只接收 configured/IP，不接收设备 Token。导入完成提示凭据已保存，用户仍须读取挂灯状态验证局域网通信。扫码会话与二维码不保存到 localStorage、不记录日志。

集成后 `npm run build` 成功（svelte-check 0 errors / 0 warnings；JS 67.31 kB、CSS 15.21 kB）。未使用真实账户登录、未读取真实米家设备列表、未验证云端风控或真实 Token 导入；编译通过不能替代这些验收。
